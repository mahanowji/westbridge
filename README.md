# WestBridge Immigration — پلتفرم جامع مشاوره مهاجرت بین‌المللی

سامانه چندزبانه (فارسی / انگلیسی) مشاوره تخصصی مهاجرت برای **۹ کشور برتر جهان**:
- 🇦🇺 **استرالیا (Australia)**
- 🇨🇦 **کانادا (Canada)**
- 🇬🇧 **انگلستان (United Kingdom)**
- 🇩🇪 **آلمان (Germany)**
- 🇳🇱 **هلند (Netherlands)**
- 🇫🇮 **فنلاند (Finland)**
- 🇪🇸 **اسپانیا (Spain)**
- 🇮🇹 **ایتالیا (Italy)**
- 🇳🇿 **نیوزیلند (New Zealand)**

توسعه‌یافته با **React 18 + Vite + MUI (Material UI) + Emotion + Stylis (پشتیبانی کامل RTL و LTR)**.

---

## ویژگی‌ها و تغییرات نسخه جدید (Multi-Country Global Edition)

1. **اضافه شدن ۵ کشور جدید اروپایی به ۳ کشور قبلی:**
   - **آلمان:** ۳۴ مسیر ویزا (کارت شانس Chancenkarte، بلوکارت آلمان، آوسبیلدونگ، فریلنسری و ...)
   - **هلند:** ۲۹ مسیر ویزا (سال جهت‌یابی Zoekjaar فارغ‌التحصیلان برتر، نیروی ماهر Kennismigrant، استارتاپ و ...)
   - **فنلاند:** ۲۸ مسیر ویزا (فست‌ترک ۱۴ روزه Specialists، استارتاپ Business Finland، اقامت تحصیلی و ...)
   - **اسپانیا:** ۳۰ مسیر ویزا (نومد دیجیتال DNV با قانون بکام، تمکن مالی Non-Lucrative، ویزای طلایی و ...)
   - **ایتالیا:** ۳۱ مسیر ویزا (ویزای نومد دیجیتال ۲۰۲۴، بورسیه DSU، سهمیه کاری Decreto Flussi و ...)
   - **مجموعاً بیش از ۲۸۰ ویزای کاربردی و رسمی** در ۸ دسته‌بندی مهاجرتی.

2. **به‌روزرسانی جامع متون و پیام برند:**
   - حذف محدودسازی‌های قدیمی به «استرالیا، کانادا، انگلستان» در تمام صفحات و جایگزینی با عبارات جامع مهاجرت بین‌المللی و مقایسه همه‌جانبه مقاصد.

3. **سیستم فیلتر آبشاری هوشمند در فرم مشاوره (`ContactForm.jsx`):**
   - پشتیبانی از ۸ کشور مقصد با بارگذاری داینامیک ویزاهای اختصاصی هر کشور دسته‌بندی‌شده بر اساس دسته‌های مهارتی، تحصیلی، خانوادگی و تجاری.

4. **سوالات متداول تب‌بندی‌شده (`FAQ.jsx`):**
   - افزودن تب‌های مجزا و پاسخ به پرسش‌های کاربردی هر ۸ کشور همراه با سوالات عمومی مقایسه‌ای اروپا در مقابل اقیانوسیه/کانادا.

5. **طراحی و استایل UI/UX:**
   - حفظ ۱۰۰٪ تم، پالت رنگی هماهنگ (Eucalyptus, Brass, Ink, Sand/Paper)، حالت Dark/Light و هماهنگی فونت Vazirmatn.

## نحوه اجرای پروژه

```bash
npm install
npm run dev
```

پروژه به صورت پیش‌فرض روی آدرس `http://localhost:5173` اجرا می‌شود.

## خروجی نهایی برای انتشار

```bash
npm run build
```
پوشه `dist/` آماده دیپلوی روی هاست استاتیک، Vercel، Netlify یا Nginx است.
